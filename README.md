# Hybrid Biomedical Image Analysis

An end-to-end biomedical image analysis pipeline combining **U-Net deep learning segmentation**, **classical image processing**, and **local Large Language Model (LLM) reasoning** for structured and auditable fluorescence microscopy image analysis.

The project compares direct Vision-Language Model (VLM) interpretation, classical Otsu segmentation, U-Net segmentation, numbers-first LLM reasoning, and a final hybrid pipeline.

The main aim is to investigate whether extracting quantitative information before LLM reasoning can improve factual grounding, reduce hallucination, and make AI-generated microscopy analysis more auditable.

---

## Project Overview

The final hybrid pipeline follows a numbers-first approach:

```text
Raw 256 × 256 Image
        ↓
PyTorch U-Net
        ↓
Binary Segmentation Mask
        ↓
Connected Components + Region Properties
        ↓
Deterministic Quality Gate
        ↓
Factual Numerical Summary
        ↓
Local LLM
        ↓
Validated Structured JSON
        ↓
Natural-Language Narrative + CSV Export
```

The numerical measurements generated by the image-analysis stages are treated as the **source of truth**. The LLM is used to organise and interpret these measurements rather than independently estimate numerical information from the raw image.

## Dataset

The project uses **112 synthetic fluorescence microscopy images** with corresponding segmentation masks.

### Dataset Split

| Split | Number of Images |
|---|---:|
| Training | 80 |
| Validation | 20 |
| Test | 12 |
| **Total** | **112** |

The dataset contains four density regimes.

| Density | Images | Mean Nuclei Count | Mean Area Coverage |
|---|---:|---:|---:|
| Sparse | 20 | 8.15 ± 1.76 | 2.25% ± 0.77% |
| Normal | 56 | 26.27 ± 6.83 | 7.01% ± 1.99% |
| Dense | 18 | 67.06 ± 13.56 | 16.94% ± 3.15% |
| Clustered | 18 | 44.06 ± 8.65 | 9.19% ± 1.56% |
| **Overall** | **112** | **32.45 ± 20.12** | **8.10% ± 4.86%** |

All images are processed as **256 × 256 grayscale images** and normalised to the range `[0, 1]`.

## Pipeline Components

### 1. Direct Vision-Language Model Analysis

The first experiment evaluates direct VLM interpretation of fluorescence microscopy images.

A naive prompt is compared with an optimised biomedical prompt designed to:

- remain descriptive rather than diagnostic;
- avoid unsupported clinical or biological conclusions;
- return structured JSON;
- explicitly represent uncertainty;
- improve reproducibility using deterministic inference settings.

Model provenance is recorded so that the requested and actual models used during inference can be audited.

---

### 2. Classical Image Analysis

Classical segmentation is performed using:

- Otsu thresholding;
- morphological closing;
- hole filling;
- small-object removal;
- connected-component labelling;
- `skimage.measure.regionprops`.

The extracted morphometric features include:

- object count;
- area;
- perimeter;
- eccentricity;
- solidity;
- foreground intensity;
- foreground coverage.

These deterministic measurements provide the factual input for the numbers-first LLM stage.

---

### 3. Numbers-First LLM Reasoning

Instead of allowing the LLM to estimate measurements directly from the raw image, the numbers-first approach provides the model with numerical measurements calculated by the image-processing pipeline.

An example structured output is:

```json
{
  "n_objects": 9,
  "density_class": "sparse",
  "shape_regularity": "regular",
  "quality_flag": "pass",
  "rationale": "..."
}
```

The pipeline includes:

- JSON extraction;
- JSON validation;
- schema validation;
- retry and fallback handling;
- numerical audit checks.

This design reduces the opportunity for the LLM to invent quantitative measurements that were not produced by the image-analysis pipeline.

## U-Net Segmentation

A four-level **SmallUNet** architecture is implemented using PyTorch.

### Architecture

```text
16 → 32 → 64 → 128 filters
```

The network uses:

- 2 × 2 max pooling;
- transpose convolutions;
- encoder-decoder skip connections;
- binary semantic segmentation.

The model predicts a binary foreground/background mask for the microscopy image.

### Training Configuration

| Parameter | Setting |
|---|---|
| Epochs | 15 |
| Optimiser | Adam |
| Learning rate | 0.001 |
| Batch size | 8 |
| Random seed | 42 |
| Augmentation | Random flips |

## Loss-Function Ablation

Three loss functions were compared during U-Net training:

1. Binary Cross-Entropy (BCE)
2. Soft Dice
3. Combined BCE + Dice

| Loss Function | Final Val Dice | Final Val IoU | Peak Val Dice | Peak Epoch |
|---|---:|---:|---:|---:|
| Combined BCE + Dice | 0.9901 | 0.9804 | 0.9902 | 13 |
| BCE Only | **0.9934** | **0.9869** | **0.9938** | 13 |
| Soft Dice Only | 0.9673 | 0.9373 | 0.9738 | 13 |

BCE-only achieved the highest peak validation Dice. The combined-loss checkpoint was retained for the final hybrid pipeline because it explicitly considers both pixel-level classification and segmentation overlap.

## U-Net vs Classical Otsu

Classical Otsu and U-Net segmentation were evaluated against the same **12 unseen test images**.

| Method | Mean Dice | Mean IoU |
|---|---:|---:|
| Classical Otsu | 0.9776 | 0.9562 |
| **U-Net** | **0.9891** | **0.9784** |

The U-Net achieved higher mean Dice and IoU, indicating better overall pixel-level agreement with the ground-truth masks.

## Final Hybrid Pipeline

The final system combines deep-learning segmentation, deterministic feature extraction, quality control, and LLM reasoning.

```text
Image
  ↓
U-Net Segmentation
  ↓
Connected-Component Analysis
  ↓
Morphometric Feature Extraction
  ↓
Deterministic Quality Gate
  ↓
Numbers-First LLM
  ↓
Validated JSON
  ↓
Narrative + Aggregated CSV
```

Across the **12 unseen test images**, the U-Net achieved approximately:

```text
Mean Dice = 0.9891
Mean IoU  = 0.9784
```

The LLM reproduced the connected-component count supplied by the deterministic analysis in **12/12 test cases**, resulting in a **100% measurement-reproduction audit match**.

This does not represent 100% true nucleus-count accuracy. The audit measures whether the LLM correctly preserved the numerical count supplied by the deterministic analysis.

## Semantic Segmentation vs Nucleus Counting

An important finding of this project is that a high segmentation Dice score does not necessarily mean that every individual nucleus has been counted correctly.

The U-Net performs **binary semantic segmentation**.

Individual objects are subsequently estimated using connected-component analysis.

Touching or overlapping nuclei can therefore be represented accurately as foreground pixels while being merged into a single connected component.

The project consequently distinguishes between:

```text
Ground-truth nucleus count
```

and:

```text
Predicted connected-component count
```

This distinction allows segmentation quality and object-count accuracy to be evaluated separately.

---

## Deterministic Quality Gate

A pre-LLM quality gate is included to prevent clearly invalid segmentation outputs from reaching the language model.

The current quality rules reject an image when:

```text
Foreground coverage > 75%
```

or:

```text
Intensity range < 0.08
```

Rejected samples do not proceed to LLM interpretation.

This prevents severe segmentation failures from being converted into potentially misleading natural-language reports.

---

## Robustness Experiment

The hybrid pipeline was tested under:

- clean conditions;
- strong blur;
- severe low contrast.

| Image | Condition | Intensity Range | Coverage | Components | Quality Gate |
|---|---|---:|---:|---:|---|
| test_000 | Clean | 0.3468 | 2.37% | 8 | Pass |
| test_000 | Blur | 0.1836 | 3.91% | 7 | Pass |
| test_000 | Low contrast | 0.0505 | 100.00% | 1 | **Reject** |
| test_004 | Clean | 0.3468 | 21.83% | 42 | Pass |
| test_004 | Blur | 0.2847 | 37.51% | 15 | Pass |
| test_004 | Low contrast | 0.0505 | 100.00% | 1 | **Reject** |

Blurring reduced the number of connected components, particularly in the higher-density image, suggesting that neighbouring nuclei were increasingly merged.

Under severe low contrast, the segmentation failed by predicting the entire image as foreground. The deterministic quality gate identified these cases and rejected them **before LLM reasoning**.

## Main Findings

The main findings of the project are:

- Direct VLM interpretation can produce plausible but unsupported statements.
- Numbers-first LLM reasoning provides stronger factual grounding.
- U-Net achieved better pixel-level segmentation than classical Otsu on the unseen test set.
- High Dice and IoU scores do not guarantee accurate individual nucleus counting.
- Touching nuclei remain challenging for connected-component analysis.
- Structured JSON improves the auditability of LLM outputs.
- Numerical audit checks help identify inconsistencies between deterministic measurements and LLM responses.
- Deterministic quality gating can prevent severe segmentation failures from reaching the LLM.
- External validation is required before the system could be considered for real clinical use.

---

## Limitations

The main limitation is that the dataset contains only **112 synthetic microscopy images**.

Therefore, the strong segmentation results should not be interpreted as evidence of clinical validity.

Additional limitations include:

- the domain gap between synthetic and real microscopy images;
- merging of touching nuclei;
- binary semantic rather than instance segmentation;
- dependence on locally available LLM/VLM models;
- the need to validate LLM-generated narratives;
- quality-gate thresholds requiring validation on larger datasets.
